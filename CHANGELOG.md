# Changelog

All notable changes to **Resource Monitor** will be documented here.

## [1.0.0] - 2026-04-21

### Added

- CPU usage % with optional inline temperature
- Memory (RAM) usage in GB / MB / percent
- GPU utilization % with optional inline temperature
- VRAM used / total
- Disk I/O read & write speed
- Network download & upload speed
- Battery level with charging indicator
- Running process count
- Customizable display order via `resourceMonitor.order`
- Color-coded alerts: warning at 70%, critical at 90%
- Toggle on/off command
- Configurable status bar position, priority, and update interval
